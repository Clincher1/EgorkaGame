# Деплой и внутреннее тестирование в VK

Цель: бесплатный хостинг 24/7 (Render), игра открывается внутри ВКонтакте
по ссылке `https://vk.com/app54850918` у администраторов и тестеров **до**
прохождения модерации.

## 1. Деплой на Render (один раз, ~10 минут)

1. Зайти на <https://render.com> → Sign up → **Get started for free** →
   войти через GitHub (права только на репозиторий EgorkaGame).
2. Dashboard → **New +** → **Blueprint**.
3. Выбрать репозиторий `Clincher1/EgorkaGame`, ветку
   `arena/8b6105ca-egorkagame` (после мержа — `main`).
   Render сам прочитает `render.yaml` и создаст сервис `egor-pto-game`.
4. На шаге переменных окружения ввести **только секрет**:
   - `VK_SECRET` = защищённый ключ приложения
     (dev.vk.com → приложение 54850918 → Настройки → Разработка).
   Остальное уже зашито в Blueprint: `VK_APP_ID=54850918`,
   `CENSOR_MODE=symbols`, `PERMADEATH=false`.
5. Create → дождаться сборки (5–7 минут). Адрес вида
   `https://egor-pto-game.onrender.com`. Проверить: открыть
   `https://egor-pto-game.onrender.com/healthz` — должно вернуть `{"status":"ok"}`.

Особенность бесплатного тарифа: сервис засыпает после 15 минут простоя,
первый запрос будит его ~30–60 секунд. Для теста и каталога это допустимо;
VK Storage не зависит от диска Render, сохранения не теряются.

## 2. Подключение адреса в кабинете VK

1. dev.vk.com → приложение **54850918** → Настройки → **Размещение**.
2. В поле адреса приложения вставить `https://egor-pto-game.onrender.com/`
   (точный URL сервиса Render, со слешем в конце, без путей).
3. Сохранить. VK сам подставит подписанные launch params при запуске —
   сервер проверяет подпись HMAC-SHA256 по `VK_SECRET`.
4. Открыть `https://vk.com/app54850918` — приложение запустится внутри VK
   у владельца аккаунта, даже пока стоит статус «Непроверенное».

## 3. Добавление тестеров (игра по VK ID до модерации)

1. Кабинет приложения → Настройки → **Управление** (или раздел «Доступ»/
   «Тестировщики» в зависимости от версии кабинета).
2. «Добавить тестера» → вставить ссылку на страницу или VK ID → сохранить.
3. Тестировщику открыть `https://vk.com/app54850918` (с телефона — из
   официального приложения VK, с десктопа — из браузера на vk.com).
4. Состояние каждого тестера хранится в его VK Storage (ключ
   `pto_save_v1`), сервер stateless — никто не видит чужие сохранения.

## 4. Чек-лист дымовой проверки перед заявкой на модерацию

- [ ] Приложение открывается с телефона внутри VK, без ошибок подписи
- [ ] Главное меню, «Как играть», «Конфиденциальность» открываются
- [ ] Сцены, арт, портреты и звук работают; выбор делается, день меняется
- [ ] Перезапуск приложения сохраняет прогресс (VK Storage round-trip)
- [ ] Истощение: при нуле ресурса появляется таймер и кнопка ролика;
      rewarded-реклама показывается, после неё игра продолжается
- [ ] «Новая игра» сбрасывает прогресс; модалки закрываются по клику вне
- [ ] Нигде нет упоминаний Telegram и ссылок на сторонние ресурсы
- [ ] Весь текст на русском, мат заменён символами `№;%:?*`

## 5. Подача на модерацию

Кабинет → раздел **Модерация** → заполнить карточку (тексты из
`docs/VK_APP_PROFILE.md`), загрузить иконку 512×512 и скриншоты,
отправить. Срок проверки — от 3 рабочих дней; до вердикта приложение
остаётся доступным тестерам.
