# Деплой на Amvera (российский хостинг, работа без VPN)

Amvera — российский PaaS: серверы в РФ, оплата рублями, бесплатный поддомен
с HTTPS, сборка из GitHub по Dockerfile. Игроки из РФ открывают приложение
без VPN — это требование прохождения модерации VK.

Конфигурация уже в репозитории: `amvera.yml` (Docker, порт 8080) и `Dockerfile`.
Постоянный диск не нужен: в VK-режиме сохранения живут в VK Storage,
сервер stateless и в файловую систему не пишет.

## 1. Создание проекта

1. <https://cloud.amvera.ru/projects> → оранжевая кнопка **«Создать проект»**.
2. Тип — **Приложение** (не PostgreSQL и не преднастроенный сервис).
3. Имя проекта латиницей, например `ptosnik` — из него соберётся домен
   вида `ptosnik-clinchrus.amvera.io`.
4. Тариф — **«Пробный»** (см. раздел 1.1). Источник кода подключается после
   создания, на вкладке «Репозиторий» (раздел 1.2).

### 1.1. Почему хватает «Пробного» (170 ₽/30 дней, 133 МБ ОЗУ)

Замер реального процесса в VK-режиме: RSS ~36 МБ в покое и под нагрузкой,
запас ~97 МБ. aiogram не импортируется без BOT_TOKEN (ленивый импорт в
`game/main.py`, страж — `tests/test_startup_footprint.py`), поэтому
младший тариф подходит с трёхкратным запасом. Повышать до «Начального»
имеет смысл только если в логах появятся OOM-перезапуски.

### 1.2. Подключение GitHub через вебхук (репозиторий публичный)

Делается один раз, полностью в веб-интерфейсе, без git в консоли.

**A. Токен GitHub (fine-grained):**
1. GitHub →右上头像 → Settings → Developer settings → Personal access
   tokens → Fine-grained tokens → Generate new token.
2. Repository access → Only select repositories → `Clincher1/EgorkaGame`.
3. Permissions → Repository permissions:
   - **Contents: Read-only**
   - **Webhooks: Read and write**
4. Expiration — 90 дней (потом можно перевыпустить и обновить в Amvera).
5. Generate token → скопировать значение (показывается один раз).
   Альтернатива: classic-токен с единственной галочкой `repo`.

**B. Amvera → проект ptosnik → вкладка «Репозиторий»:**
1. Раскрыть **«Подключить GitHub, GitLab, Bitbucket»** (первый блок,
   не «ручная настройка»).
2. Git service: **GitHub**; событие: **Push**.
3. Секрет — сгенерировать кнопкой или придумать длинную случайную строку,
   сохранить (вставим его и на стороне GitHub).
4. Вставить токен из шага A.
5. Ветка: `arena/8b6105ca-egorkagame` (копировать точно, регистр важен).
6. Нажать «Подключить» и **скопировать показанный URL вебхука**.

**C. GitHub → репозиторий → Settings → Webhooks → Add webhook:**
1. Payload URL = URL из шага B.6.
2. Content type = **application/json**.
3. Secret = тот же секрет из B.3.
4. События: **Just the push event**; галочка Active включена.
5. Add webhook. Зелёная галочка у доставки означает успех.

После этого каждый `git push` в ветку автоматически запускает сборку.
Первый билд можно инициировать пустым коммитом (`git commit --allow-empty`)
или кнопкой пересборки в Amvera.

Выделенный репозиторий Amvera (третий вариант на экране) — запасной путь:
`git remote add amvera https://git.amvera.ru/clinchrus/ptosnik` и
`git push amvera arena/8b6105ca-egorkagame:master`, но он требует git
локально и пароля Amvera.

### 1.3. Что игнорировать на экране проекта

- Плашка «Сохраняйте SQLite в /data» — не про нас: приложение stateless,
  все сохранения лежат в VK Storage, файловая система контейнера не нужна.
- Баннер про восстановление региона Москва_0/Москва_1 — внутренняя
  инфраструктура Amvera, действий не требует.

## 2. Переменные окружения

В настройках проекта раздел переменных окружения/секретов. Значения:

| Переменная | Значение | Тип |
|---|---|---|
| `VK_APP_ID` | `54850918` | обычная |
| `VK_SECRET` | защищённый ключ из кабинета VK (Разработка → Ключи доступа) | **секрет** |
| `CENSOR_MODE` | `symbols` | обычная |
| `PERMADEATH` | `false` | обычная |
| `WEB_PORT` | `8080` | обычная |

`VK_SECRET` в git и чаты не попадает — только в это поле. Если платформа
спросит health-check путь: `/healthz`.

## 3. Сборка, запуск и внешний домен

1. Push в подключённую ветку запускает сборку автоматически (первый билд
   3–7 минут: тянется python:3.11-slim, у Amvera есть прокси до Docker Hub).
2. Дождаться статуса **«Запущено»**, реплик 1/1.
3. По умолчанию создан только **внутренний** домен `run-<проект>` — он
   недоступен из интернета. Нужен внешний:
   - вкладка **«Домены»** → оранжевая кнопка **«Создать доменное имя»**;
   - тип подключения: **HTTPS** (SSL выпустится автоматически, 1–2 минуты);
   - тип домена: **«Бесплатный домен Амвера»**;
   - если мастер спросит маршрут: путь `/`, порт `8080` (значение
     `containerPort` из `amvera.yml`);
   - применить и дождаться привязки. Адрес вида
     `https://ptosnik.clinchrus.amvera.io/` (точный формат покажет интерфейс).
4. Открыть `https://<домен>/healthz` — должен ответить `{"status": "ok"}`.
   Затем открыть корень `https://<домен>/` — в обычном браузере игра
   работает в анонимном веб-режиме, можно прогнать меню, сцены и звук.
5. Если статус «работает с ошибкой» — смотреть вкладку «Логи»; самые частые
   причины: забытая переменная `VK_SECRET` или неверный `containerPort`
   (в нашем `amvera.yml` уже 8080).

## 4. Подключение к VK и проверка без VPN

1. dev.vk.com → приложение 54850918 → Настройки → **Размещение** →
   вставить `https://<домен>.amvera.io/` (со слешем в конце) → Сохранить.
2. С телефона **с выключенным VPN** открыть `https://vk.com/app54850918`
   и по мобильному интернету, и по Wi-Fi.
3. Прогнать чек-лист из `docs/VK_DEPLOY.md` (меню, сцены, звук,
   сохранение после перезапуска, кнопка ролика при истощении).
4. Тестеров добавлять в разделе **Тестовые группы** кабинета VK.

## 5. Деньги и баланс

- Тарификация поминутная, списания только пока контейнер в статусах
  «запущено» / «работает с ошибкой».
- «Пробный» — 170 ₽/30 дней круглосуточно (≈0,24 ₽/час): бонусных 110 ₽
  хватает примерно на 19 дней непрерывной работы — с запасом на внутреннее
  тестирование и модерацию (3 рабочих дня), при остановках на паузу — дольше.
- Если тесты на паузе — проект можно останавливать кнопкой в Amvera,
  списание прекращается. Перед подачей на модерацию вернуть в запуск.
- После релиза пополнить баланс любым российским способом оплаты.

## 6. Обновления игры

Push в подключённую ветку → Amvera автоматически пересобирает проект
(или кнопка «Пересобрать»). Секреты при этом не сбрасываются.
