# Роадмап VK-версии «ПТОшник Егор»

Цель: публикация в каталоге VK Games / VK Mini Apps с прохождением модерации
с первого-второго раза. Решения по согласованию:

- стиль: **премиальный ретро-терминал** + иллюстрации сцен, анимации, звук;
- монетизация на старте: **rewarded-реклама** (Голоса VK — следующим этапом);
- сохранения: **VK Storage** (родное key-value хранилище, лимит значения 4096 байт);
- площадка: **сначала VK**, Telegram-адаптер остаётся в коде, но не в VK-сборке.

## Почему так (по правилам VK)

| Правило VK | Что делаем |
|---|---|
| Запрет мата (1.3 правил каталога) | Модуль `game/censor.py`: замена на символы `;%:?*` и фирменные эвфемизмы |
| Запрет чужих соцсетей/логотипов (3.13, 4.2.6) | Отдельная VK-сборка: без Telegram SDK и упоминаний |
| Энергия обязана восстанавливаться по таймеру (4.2.8) | Вместо концовки при нуле — режим «восстановление», платный/рекламный пропуск ожидания |
| Нельзя блокировать геймплей неплатящим (2.3) | Ожидание ограничено по времени, реклама — лишь ускорение |
| Стартовое меню, правила, обучение (3.2, 4.2.10) | Экраны меню, «Как играть», политика конфиденциальности |
| Геймплей > 10 минут (4.2.7) | Уже выполняется: 10 сюжетных дней, 15–25 минут |
| Только русский язык (3.1) | Выполнено |
| HTTPS, без плагинов (3.11, 3.12) | aiohttp + статика, уже так |
| Никакой сторонней авторизации и персданных (3.10) | Игрок опознаётся по подписанным launch params VK |

## Принципы

- Игровое ядро (`engine.py`, `models.py`, `content.py`) не знает про VK:
  платформенные отличия живут в адаптерах и флагах конфигурации.
- Любая правка покрывается тестом; `pytest` и `ruff` — зелёные перед каждым PR.
- Telegram-версия не ломается: VK-режим включается отдельно, дефолт — как сейчас.
